Halo Sky Gram

Cloud by height and time for any place, from ECMWF model data via Open-Meteo, in local time. The height gram shades cloud cover on 13 pressure levels with the 0, −15 and −40 °C isotherms; the low/mid/high gram shows ECMWF's own three cloud bands.

Gram

Choose a place and period, then Draw gram.

Data: ECMWF IFS via Open-Meteo, licensed CC BY 4.0. Height gram: IFS 0.25° (about 25 km) temperature, cloud cover and geopotential height on 13 pressure levels, available from January 2024; cloud cover on pressure levels is derived from relative humidity. Low/mid/high: IFS HRES 9 km, from January 2017; ECMWF splits the bands at 0.8 and 0.45 of surface pressure (dashed lines in the height gram). Each gram is fetched directly from Open-Meteo's free, non-commercial API by your browser; no key is used.
